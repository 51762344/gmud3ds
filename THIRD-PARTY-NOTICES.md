## Original game

The name, characters, maps, artwork, story and text of *Bai Jin Ying Xiong Tan Shuo* (白金英雄坛说) belong to their respective rights holders.

- This repository contains no data files extracted from the original game; `data/` and `romfs/` must be generated by the user from a copy they legally hold.
- `icon.png`, `icon_small.png` and the pixel matrices in `tools/icon_art.py` paste the original hero sprite's pixels and recolour them 1:1 using only the classic-green four-shade palette from `source/gfx.c`. Copyright remains with the original rights holders; these files will be removed on request.
- Some in-game names, prompts and dialogue lines remain in the source; they originate from the original game and are used only for compatibility with its gameplay.
- `assets/banner/` is drawn by `tools/banner_build.py` from GNU Unifont glyphs plus a synthesized chime; it contains no original artwork.

This is an unofficial fan project, not affiliated with the original rights holders and not representing their views.
